# Phase B18 - UX Decisions

## Patterns Reviewed

- The existing people icon is the correct shell location for testing persona/user-role context.
- Dialog content must scroll because some communities define three personas.

## Decisions

- The people icon opens a modal picker labelled `Test persona`.
- The picker includes a local-testing disclaimer.
- The active persona card appears in the community screen.
- Persona options use plain list tiles rather than deprecated radio APIs.

- B18 Android screenshots show the picker dialog and member-selected state.
