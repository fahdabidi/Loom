# Phase B20 - UX Decisions

## Patterns Reviewed

- Multi-persona tests must prove both the producer action and the receiver continuation.
- Evidence should include before, action, and completion screenshots for the cross-persona handoff.

## Decisions

- Masjid Nur is the screenshot-backed reference chain: admin publishes public announcement, member
  receives it after persona switch.
- All other communities are covered by the exhaustive widget sweep to avoid reducing screenshots to
  a single all-powerful actor.
- The final manifest remains phase-grouped but B20 owns the combined B12-B20 closeout.

## Evidence

- B20 Android screenshots include admin start/action/complete and member ready/action/received states.
