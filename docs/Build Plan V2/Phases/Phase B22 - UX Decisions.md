# Phase B22 - UX Decisions

## Decisions

- Rename the visible workflow section from `Workflow checklist` to `Community workflows`.
- Replace generic actor button copy with semantic labels such as `Publish announcement`,
  `RSVP to event`, `Pay and save receipt`, `Generate export`, and `Open Messages`.
- Replace generic action dialogs with production review dialogs that show action, inputs, validation,
  result, and trust summary.
- Add workflow category and surface chips so users can distinguish event, payment, publishing,
  approval, portability, platform, and form surfaces.
- Replace generic completion chips with domain result states such as `Sent`, `Receipt`, `Decided`,
  `Ready`, `Verified`, `Going`, or `Saved`.

## Evidence

- `wf_domain-specific-workflow-surfaces` passes.
- Full Demo App widget suite passes.
- Android workflow screenshot evidence was refreshed after this implementation.
