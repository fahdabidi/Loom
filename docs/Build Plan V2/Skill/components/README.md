# Component Guides

Set A phases add one guide per built component.

Each guide must include:

- Purpose.
- Contract.
- Required permissions.
- Key operations.
- Events emitted/consumed.
- Owned data and export notes.
- Recipes for extension builders.
- Gotchas beyond OpenAPI.
- Minimal snippet or manifest fragment.
- Validation and consumer-contract tests.
