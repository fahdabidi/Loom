# Workflow Guides

Set B phases add one guide per workflow.

Each guide must include:

- Workflow purpose.
- End state.
- Components involved.
- Extension artifacts required.
- Step-by-step implementation.
- Fixtures and tests.
- Failure modes and owning components.
- Example extension fragment.
