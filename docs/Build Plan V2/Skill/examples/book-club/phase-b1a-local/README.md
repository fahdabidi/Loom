# Book Club B1a Local Example

This example is the first local-demo package pair used by the Skill.

## Extension Package

- `extensionId`: `ext_book_club`
- `version`: `1.0.0`
- `permissions`: `content.publish`
- bundled assets: logo, card image, hero image, default card image

## Initialization Package

- `communityId`: `community_book_club`
- `displayName`: `Neighborhood Book Club`
- seed files: `seed/community.json`, `seed/workflows.json`
- card asset: `asset_card_book_club`

## Validation

- `wf_local-demo-prereq-to-validation-ready`
- `wf_local-build-download-sideload-install`
