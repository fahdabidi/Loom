# Prompt Build Validate Complete

Use this workflow before claiming that an arbitrary local-demo extension generated by the Skill is
implemented.

## Process

1. Capture the owner prompt and save it as a prompt fixture.
2. Extract community identity, personalization, and every requested target workflow.
3. Produce owner-review docs:
   - `requirements.md`
   - `workflows.md`
   - `major-ui-screens.md`
   - `major-features.md`
   - `ui-guidelines.md`
4. Generate the `.loom-extension.zip` package.
5. Generate the `.loom-init.zip` initialization package.
6. Load the generated package pair through the Demo App Local Backend.
7. Render/open the generated extension via App Shell as `local:<extension-id>@latest`.
8. Validate every requested workflow against the generated manifest and initialization package.
9. Write `validation-report.json` and `validation-report.md`.
10. Report complete only when every workflow result has `implemented=true`, `validated=true`, and
    `complete=true`.

## Required Evidence

- Prompt fixture path.
- Generated review-doc paths.
- Generated package paths.
- Imported community name.
- Open extension route.
- Per-workflow validation result.
- Final `complete` boolean.
