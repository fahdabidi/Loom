# Book Club Phase B2 Headline Example

This example adds the first complete vertical workflow on top of the local/publish package artifacts.

Workflow elements:

- Nomination form: `book_nomination`
- Monthly poll: `book_vote`
- Meeting event: `Discuss Parable of the Sower`
- Discussion thread: `book_discussion`
- Digest query: `Parable`

Validation:

- `wf_book-club-headline`
