# Arbitrary Garden Club Example

This example is the B10 arbitrary Skill-output replay fixture. It is intentionally not one of the
anchor verticals, so it proves the local-demo loader consumes generated package contents instead of
falling back to Book Club or another built-in sample.

## Files

- `loom.extension.json`: local-demo extension manifest generated by the Skill.
- `loom.initialization.json`: fake-backend initialization package generated by the Skill.

## Validation

The B10 workflow test copies these JSON files into temporary files with the locked local-demo package
suffixes:

- `garden-club.loom-extension.zip`
- `garden-club.loom-init.zip`

The Demo App Local Backend parses those files, imports the declared community, renders the Garden Club
card, and opens `local:ext_garden_club@latest`.
