# Loom Communities Demo App

Use the Demo App to validate local-demo packages and initialization packages before hosted publish exists.

## Extension Use

- Start with no communities.
- Use Add Community to load local extension and initialization packages.
- Confirm a branded card appears and opens inside the shell.

## Validation

- `vt_demo-app_empty-community-state`, `vt_demo-app_add-community-button`, `vt_demo-app_cards-after-load`, and `vt_demo-app_open-local-extension` prove the local demo loop.
